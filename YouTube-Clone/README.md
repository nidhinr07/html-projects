# YouTube Clone

This is a YouTube clone project that I built using HTML and CSS.

I created this project to practice frontend development and improve my understanding of layouts, navigation bars, video cards, responsive design, and recreating a real-world website interface.

## Features

* YouTube-style header
* Search bar
* Sidebar navigation
* Video categories
* Video thumbnail cards
* Channel information
* Video duration labels
* Responsive layout
* Hover effects

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Fixed positioning
* Responsive design
* Card layouts
* Image styling
* Navigation layouts
* Hover effects
* Spacing and alignment
* Media queries

## Purpose

The main purpose of this project was to practice HTML and CSS by recreating the basic layout and interface of YouTube.

This is a frontend practice project and is not connected to the actual YouTube platform.

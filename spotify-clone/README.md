# Spotify Clone

This is a Spotify clone project that I built using HTML and CSS.

I created this project to practice frontend development and improve my understanding of layouts, responsive design, styling, and recreating a real-world music streaming interface.

## Features

* Spotify-style sidebar navigation
* Home and music sections
* Playlist and album cards
* Artist sections
* Music player section
* Song information and controls
* Dark theme
* Hover effects
* Responsive design

## Technologies Used

* HTML5
* CSS3
* Font Awesome
* Responsive Design

## What I Practiced

* HTML page structure
* CSS Flexbox
* CSS Grid
* Responsive design
* Card layouts
* Image styling
* Hover effects
* Positioning
* Spacing and alignment
* Creating a music player interface

## Purpose

The main purpose of this project was to practice HTML and CSS by recreating the basic interface of Spotify.

This is a frontend practice project and is not connected to the actual Spotify platform.
